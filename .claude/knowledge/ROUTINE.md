## 1. 자동 학습 루틴

- **이름**: 구운록 자동 학습 (일일 리서치)
- **스케줄**: 매일 18:00 UTC = 03:00 KST
- **하는 일**: `research-queue.md`의 다음 주제를 웹 리서치 → `topics/`에 노트 작성
  ("구운록 적용 아이디어" 필수) → INDEX/큐/로그 갱신 → `claude/knowledge-base`
  브랜치에 커밋·푸시. 별도 worktree에서 작업해 개발 중인 작업 트리를 건드리지 않음.
- **범위 제한**: `.claude/knowledge/` 아래만 수정. PR 금지.

## 2. 일일 개발 제안 루틴 (Stage 0)

- **이름**: 구운록 일일 개발 제안 (Stage 0)
- **스케줄**: 매일 21:00 UTC = 06:00 KST
- **하는 일**: AUTONOMY_RULES.md 준수 하에,
  - 미응답 제안 이슈가 열려 있으면 → 아무것도 안 함 (리마인더 금지)
  - "수정 요청" 댓글이 있으면 → 개정판(-r2)을 같은 이슈에 작성
  - "승인" 댓글이 있으면 → Stage 0이므로 개발 시작 없이 대표에게 보고만
  - 열린 제안이 없으면 → P0 직결 작업 1개를 `[개발 제안] GR-YYYYMMDD-1: …` 이슈로 생성
- **범위 제한**: 코드 수정·PR·병합 금지. 이슈 작성만.
- **승인 판정**: 저장소 소유자(`ants1016-a11y`) 계정의, 작업 ID가 포함된 댓글만 유효.
